# SPACEFLIGHTS — Quick Idea

`SPACEFLIGHTS` is a minimalist 3D wireframe space game about tension without combat.

## The Pitch
You command a main ship that keeps traveling through deep space while you manage systems, deploy an exploration module, and sometimes go out as an astronaut on a tether.

The challenge is not enemies — it is distance, precision, and keeping things together before you drift too far.

## Core Feel
- Calm but tense
- Sparse but readable
- Technical but player-driven

## What Makes It Different
- Everything is procedural wireframe (lines, points, simple geometry)
- Strong spatial orientation (starfield, distant anchors, reference grid)
- Guided inertia movement (physics-inspired but controllable)
- Real-time mode switching between:
  - Ship systems
  - Module piloting
  - EVA astronaut operations

## Core Tension Systems
- Fuel
- Signal quality/range
- Oxygen (EVA)
- Heat/damage
- Precision movement under pressure

## Mission Shape
Travel out, perform objective work, and make it back.

Typical flow:
1. Ship travels
2. Deploy module
3. Reach and operate near target
4. EVA if needed
5. Recover and return

## Visual Rules
- Black background
- White wireframe baseline
- Color accents:
  - Green = safe
  - Blue = objective
  - Red = danger

## MVP Goal
Build the playable “feel” first:
- Third-person gameplay views
- Reliable orientation in space
- Procedural seeded world
- Module/ship/EVA interactions with clear systemic tension
